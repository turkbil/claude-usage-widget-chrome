# Claude Usage Widget — 商店資訊 · 繁體中文 (zh_TW)

## Item name
Claude Usage Widget

## Short description
在工具列查看 Claude 每週上限：所有帳號、Fable、免費重設、重設時間、預測與提醒，一眼掌握。

## Detailed description

每週上限還剩多少？該先用哪個帳號？答案就在工具列上。

▸ 功能
• 記住你在這個瀏覽器登入過的每個 Claude 帳號：電子郵件、每週剩餘 %、Fable 剩餘、重設的星期與時間、每月續訂或到期日
• 未登入的帳號顯示上次登入時的資料
• 「先用這個帳號」：當某個帳號未用完的每週額度將在 48 小時內重設時提醒你
• claude.ai 發放的免費重設（↺）：次數與到期日。只顯示，絕不使用
• 目前帳號詳情：每日預算，以及本週用在哪裡（Claude Code / 聊天 / Cowork）
• 依帳號通知：用量門檻、即將結束的方案、快到期的免費重設。每則只通知一次
• 不再需要的帳號可隱藏或刪除
• 全新圖示：每週循環
• 工具列圓環或數字：每週 %、每週剩餘、5 小時 %、5 小時剩餘。各項可隱藏、顯示為文字或彩色圓環
• 用量預測：「照這個速度，週末會到 64%」或「約 1天 8小時後達上限」
• 彈出視窗中的 7 天趨勢圖
• 設定頁面，更新頻率 30 秒 / 1 分 / 5 分 / 10 分
• 15 種語言，自動偵測

▸ 隱私
• 帳號電子郵件與免費重設資訊存在這個瀏覽器（chrome.storage.local，以及若開啟同步、由 Chrome 與你的 Google 帳號同步的 chrome.storage.sync 備份），不會傳送給我們或任何人
• 只向 claude.ai 發出 GET 請求：只讀取，絕不更改你的帳號
• 沒有遙測、沒有分析、沒有第三方服務
• 不讀取也不儲存你的 Cookie：呼叫 claude.ai 時由 Chrome 自行附上
• 開放原始碼，MIT 授權：github.com/turkbil/claude-usage-widget-chrome
