# Claude Usage Widget — ストア掲載文 · 日本語 (ja)

## Item name
Claude Usage Widget

## Short description
Claude の週間上限をツールバーに。全アカウント、Fable、無料リセット、リセット時刻、予測、通知をひと目で。

## Detailed description

週間上限はあとどれくらい？どのアカウントから使うべき？その答えがツールバーにあります。

▸ 機能
• このブラウザでログインした Claude アカウントをすべて記憶：メール、週間残り %、Fable 残り、リセットの曜日と時刻、月次の更新日または終了日
• ログインしていないアカウントは最後のログイン時のデータを表示
• 「このアカウントを先に使う」：未使用の週間枠が 48 時間以内にリセットされるアカウントをお知らせ
• claude.ai が付与する無料リセット（↺）：回数と有効期限。表示するだけで、使うことはありません
• 使用中アカウントの詳細：1 日あたりの目安と、今週の使い道（Claude Code / チャット / Cowork）
• アカウントごとの通知：使用量のしきい値、終了するプラン、期限切れ間近の無料リセット。それぞれ 1 回だけ
• 不要なアカウントは非表示または削除
• 新しいアイコン：1 週間のサイクル
• ツールバーにリングまたは数字：週間 %、週間残り、5 時間 %、5 時間残り。それぞれ非表示・テキスト・色付きリングを選択
• 消費ペースの予測：「このペースだと週末に 64 %」または「上限まで約 1日 8時間」
• ポップアップに 7 日間のグラフ
• 設定ページ、更新間隔 30 秒 / 1 分 / 5 分 / 10 分
• 15 言語、自動判別

▸ プライバシー
• アカウントのメールと無料リセットの情報はこのブラウザ内に保存され（chrome.storage.local と、同期がオンなら Chrome が Google アカウントと同期する chrome.storage.sync のバックアップ）、私たちにも他の誰にも送信されません
• 通信先は claude.ai のみ、GET リクエストだけ：読み取るだけで、アカウントを変更することはありません
• テレメトリ、アクセス解析、第三者サービスは一切なし
• Cookie を読み取ったり保存したりしません。claude.ai への通信時に Chrome が自動で付けます
• オープンソース、MIT ライセンス：github.com/turkbil/claude-usage-widget-chrome
