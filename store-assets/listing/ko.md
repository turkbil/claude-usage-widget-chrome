# Claude Usage Widget — 스토어 등록 정보 · 한국어 (ko)

## Item name
Claude Usage Widget

## Short description
Claude 주간 한도를 도구 모음에서 확인하세요. 모든 계정, Fable, 무료 초기화, 초기화 시각, 예측, 알림까지.

## Detailed description

주간 한도가 얼마나 남았을까? 어떤 계정부터 써야 할까? 답은 도구 모음에 있습니다.

▸ 기능
• 이 브라우저에서 로그인한 모든 Claude 계정을 기억: 이메일, 주간 남은 %, Fable 남은 양, 초기화 요일과 시각, 월간 갱신일 또는 종료일
• 로그인하지 않은 계정은 마지막 로그인 때의 데이터를 표시
• "이 계정 먼저 사용": 사용하지 않은 주간 한도가 48시간 안에 초기화되는 계정을 알려 줍니다
• claude.ai가 제공하는 무료 한도 초기화(↺): 개수와 만료일. 보여 주기만 하고 절대 사용하지 않습니다
• 현재 계정 상세: 하루 예산과 이번 주 사용처(Claude Code / 채팅 / Cowork)
• 계정별 알림: 사용량 임계값, 끝나가는 요금제, 곧 만료되는 무료 초기화. 각각 한 번만
• 더 이상 필요 없는 계정은 숨기거나 삭제
• 새 아이콘: 한 주의 순환
• 도구 모음에 링 또는 숫자: 주간 %, 주간 남은 양, 5시간 %, 5시간 남은 양. 각각 숨기기, 텍스트, 컬러 링 중 선택
• 소진 속도 예측: "이 속도면 주말에 64%" 또는 "약 1일 8시간 후 한도"
• 팝업에 7일 추이 그래프
• 설정 페이지, 새로 고침 30초 / 1분 / 5분 / 10분
• 15개 언어, 자동 감지

▸ 개인정보 보호
• 계정 이메일과 무료 초기화 정보는 이 브라우저에 저장되며(chrome.storage.local, 그리고 동기화가 켜져 있으면 Chrome이 Google 계정과 동기화하는 chrome.storage.sync 백업) 저희나 다른 곳으로 전송되지 않습니다
• 요청은 claude.ai로만, GET으로만 보냅니다. 읽기만 하고 계정을 변경하지 않습니다
• 원격 측정, 분석, 서드파티 서비스 없음
• 쿠키를 읽거나 저장하지 않습니다. claude.ai를 호출할 때 Chrome이 자동으로 붙입니다
• 오픈 소스, MIT 라이선스: github.com/turkbil/claude-usage-widget-chrome
