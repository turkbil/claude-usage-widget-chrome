# Claude Usage Widget — ข้อมูลร้านค้า · ไทย (th)

## Item name
Claude Usage Widget

## Short description
ดูขีดจำกัดรายสัปดาห์ของ Claude บนแถบเครื่องมือ: ทุกบัญชี, Fable, สิทธิ์รีเซ็ตฟรี, เวลารีเซ็ต, การคาดการณ์ และการแจ้งเตือน

## Detailed description

ขีดจำกัดรายสัปดาห์เหลือเท่าไร และควรใช้บัญชีไหนก่อน? คำตอบอยู่บนแถบเครื่องมือของคุณ

▸ ฟีเจอร์
• จำทุกบัญชี Claude ที่คุณเข้าสู่ระบบในเบราว์เซอร์นี้: อีเมล, % ที่เหลือของสัปดาห์, Fable ที่เหลือ, วันและเวลารีเซ็ต, วันต่ออายุหรือวันสิ้นสุดแพ็กเกจรายเดือน
• บัญชีที่ไม่ได้เข้าสู่ระบบอยู่จะแสดงข้อมูลจากการเข้าสู่ระบบครั้งล่าสุด
• "ใช้บัญชีนี้ก่อน": เตือนเมื่อโควตารายสัปดาห์ที่ยังไม่ได้ใช้ของบัญชีใดจะรีเซ็ตภายใน 48 ชั่วโมง
• สิทธิ์รีเซ็ตฟรี (↺) ที่ claude.ai มอบให้: จำนวนและวันหมดอายุ แสดงเท่านั้น ไม่นำไปใช้
• รายละเอียดบัญชีปัจจุบัน: งบต่อวัน และสัปดาห์นี้ใช้ไปกับอะไร (Claude Code / แชต / Cowork)
• แจ้งเตือนแยกตามบัญชี: เกณฑ์การใช้งาน, แพ็กเกจที่กำลังจะสิ้นสุด, สิทธิ์รีเซ็ตฟรีที่ใกล้หมดอายุ แต่ละรายการแจ้งครั้งเดียว
• ซ่อนหรือลบบัญชีที่ไม่ต้องการแล้ว
• ไอคอนใหม่: วงรอบรายสัปดาห์
• วงแหวนหรือตัวเลขบนแถบเครื่องมือ: % รายสัปดาห์, ที่เหลือรายสัปดาห์, % 5 ชั่วโมง, ที่เหลือ 5 ชั่วโมง แต่ละรายการซ่อนได้ แสดงเป็นข้อความ หรือวาดเป็นวงแหวนสี
• คาดการณ์อัตราการใช้: "ด้วยอัตรานี้ สิ้นสัปดาห์จะถึง 64%" หรือ "ถึงขีดจำกัดในอีก ~1 วัน 8 ชม."
• กราฟ 7 วันในหน้าต่างป๊อปอัป
• หน้าการตั้งค่า, รีเฟรชทุก 30 วิ / 1 นาที / 5 นาที / 10 นาที
• 15 ภาษา ตรวจจับอัตโนมัติ

▸ ความเป็นส่วนตัว
• อีเมลของบัญชีและข้อมูลสิทธิ์รีเซ็ตเก็บไว้ในเบราว์เซอร์นี้ (chrome.storage.local และสำเนาสำรองใน chrome.storage.sync ที่ Chrome ซิงค์กับบัญชี Google หากเปิดการซิงค์) และไม่ถูกส่งมาให้เราหรือผู้ใด
• ส่งคำขอไปที่ claude.ai เท่านั้น และเป็น GET เท่านั้น: ส่วนขยายแค่อ่าน ไม่เปลี่ยนแปลงอะไรในบัญชีของคุณ
• ไม่มีเทเลเมทรี ไม่มีการวิเคราะห์ ไม่มีบริการของบุคคลที่สาม
• ไม่อ่านและไม่เก็บคุกกี้ของคุณ: Chrome แนบให้เองเมื่อเรียก claude.ai
• โอเพนซอร์ส สัญญาอนุญาต MIT: github.com/turkbil/claude-usage-widget-chrome
